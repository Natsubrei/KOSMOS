# 0004 · Time-window semantics

## Question

How is the timeline cut for diagnosis: fixed-length windows, incident-anchored windows opened by a trigger and closed by quiescence, or both? Who defines window boundaries (agent, server, or diagnosis rules), how do windows reference each other (parent/adjacent), and what must every window carry so evidence can cite it? Decide with the report model (0003) in view; keep both consistent.

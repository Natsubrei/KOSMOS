# 0003 · Report and evidence-chain data model

## Question

What exactly is in a diagnosis report? Define the data model: conclusion, evidence item, threshold, reasoning/justification, and how evidence references underlying events, windows, and the diagnosed PID/TID or resource object — such that a human can audit why the conclusion follows. This is the core domain-modeling ticket; local competitive notes (gitignored under `docs/research/`) show no open-source product does this, so the model is designed from first principles.

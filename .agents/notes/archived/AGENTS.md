# AGENTS.md — Archived Agent Notes

Archived triplets are frozen historical snapshots, not current authority.
Never edit, reformat, translate, delete, or move a sealed artifact; use an
active Agent Note or current documentation instead. The archival change itself
is defined in [the Agent Note rules](../README.md).

`scripts/verify-agent-notes.sh` checks the tree and the `Archived:` line.
`scripts/verify-md-links.sh` skips archived files as link sources. The pairing
gate still requires a complete triplet.
